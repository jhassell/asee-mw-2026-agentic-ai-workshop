# corpus/

This folder is empty on purpose.

The workshop corpus (79 engineering-education papers from the ASEE PEER
repository) is **not** distributed in this repository. ASEE granted
permission for these papers on 2026-08-26 for a specific, narrow use:
private, temporary, per-participant environments, for the duration of the
session only, never posted publicly.

`bash setup.sh` downloads the papers into your own Codespace using the
workshop code on your seat card. They land in `corpus/papers/`.

Papers remain © the American Society for Engineering Education and their
respective authors. They are provided for use during this workshop only.
Please do not redistribute them.
